# Willowbrook Ward Conference Story Challenge

Upload the contents of this folder to the root of a GitHub repository. In Settings → Pages, choose Deploy from a branch → main → /(root) → Save. Use the link GitHub shows after deployment.

The game is a static site. No install or build is required. Open index.html to try it locally, or serve this folder with any static web server.

Each leader runs an independent game on their own browser. Progress is saved locally; Save a backup / Load a backup transfers a session. One host screen is used at the activity.
