## What the review establishes

All six fireside topics have direct support. Most earlier talk summaries were sound. The revisions chiefly improve which passage leads each discussion, restore qualifications, distinguish direct teaching from a related application, and answer the original assigned questions more closely.

Each talk has two caption files, but the `.English.srt` and `English_ASR.srt` copies are **byte-for-byte identical in all 18 folders**. They are one source of wording rather than independent confirmation. Obvious recognition errors include names, the magazine in Caussé's opening, and several phrases in Chigbundu and Giuffra. Do not silently turn uncertain words into exact quotations.

The captions use overlapping cue times. Reading the fragments in cue order provides the talk text, but a cue's end is not a word-level speech timestamp. The old cards often select the right subject while choosing a cut that appears too short to include their entire displayed text. The comparison below identifies those risks from the captions; it does **not** certify any new edit against the audio.

The existing `activity.json`, prepared clips, and `clips.json` remain unchanged. They belong to the prototype and are not the final content set for the proposed game. This file records the changes to consider together when that design is implemented, so the clip files and metadata cannot silently disagree.

## Priorities for the final content set

1. Build around the six assignments and their actual questions. Add Fale's labels passage and Farnes's sacrament-to-weekday connection; use Runia's storm image for a short challenge.
2. Use subtitles to find candidates, then finalize spoken boundaries from audio. Several previous passages need extension or replacement, not just a different question.
3. Keep displayed text explicit about its status: verified quotation, abridged excerpt with marked omissions, or paraphrase. The prototype currently puts every card's text in quotation marks, even though the wording is not audio-verified.
4. Retain essential qualifications: no guarantee of an easy life, painful questions are not weakness, covenant influence does not override agency, and invitations should allow choice.
5. All 19 downloaded Sunday addresses have now been reviewed in the [first Sunday batch](Sunday%20Caption%20Review.md) and [additional seven-address review](Additional%20Talk%20Review.md). Use the combined [discussion notes](Conference%20Discussion%20Notes.md) for selection. The latest proposed activity is the [story board](Story%20Board%20Proposal.md); the six-mission design remains an alternative. Current production steps are in the [project overview](../../README.md#remaining-work).
